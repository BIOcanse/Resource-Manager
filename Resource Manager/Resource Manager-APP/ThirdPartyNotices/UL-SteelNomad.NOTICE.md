# UL Solutions / 3DMark Steel Nomad

We gratefully acknowledge UL Solutions, the 3DMark team, and the benchmark
participants whose publicly reported results support the GPU default-score data.

Source: https://benchmarks.ul.com/compare/best-gpus?amount=0&minRating=0&reverseOrder=false&sortBy=SCORE&types=MOBILE,DESKTOP

The application uses 174 unambiguous model medians from the Steel Nomad DX12
comparison table, not results measured on the user's machine. The snapshot was
retrieved on 2026-09-14 UTC (2026-09-13 America/Chicago); its source HTML SHA-256 is
98E74EF04158759D2237B53131F5C0EED5ACE749BD120F5D816B57EBBC7F87A8.
Ambiguous repeated model rows are omitted. Model names are normalized for exact
lookup; scores are not multiplied by vendor, generation, AI or game bonuses.
Users can override the defaults. An unmatched model has no benchmark default.
