## 📖 这是什么

就像名字描述的那样，**资源管理器**是一个试图监视和管理电脑所有资源的软件：CPU 计算资源、GPU 计算资源、内存、显存，以及其他各种你能想到和没想到的资源。

从使用资源管理器开始，真正掌握你的电脑！🚀

> ⚠️ 硬件读数依赖于系统上可用的驱动与数据提供方；GPU 调度依赖软件和驱动的支持，并非每个运行中的程序都能切换显卡。

> 🌐 界面语言默认跟随系统，也可以在 设置 → 外观 → 界面语言 里手动指定。截图中的机型、外设、路径等个人信息已用实心条遮盖。

## ⚡ 性能优化

界面上的三个按钮用于切换自动优化模式：**普通模式**、**仅内存管理**、**智能优化**。

![性能优化](docs/screenshots/zh/04-optimization.png)

- **🧠 仅内存管理** —— 只会对内存进行优化管理。
- **⚡ 智能优化** —— 对 CPU、GPU、内存和显存进行全方面智能管理。

**显存与内存压力。** 当你启动占用较大 GPU 资源的游戏或者专业软件时，是否遇到过显存 / 内存紧张？智能调度会识别到压力，并自动把不重要的低负载软件从独显移动到核显，避免它们白白占用显存 —— 比如 Chrome、Edge、NVIDIA App（我也不知道为什么这个东西缩在托盘里还是会占显存 🤷）。

**多显卡。** 如果你有多个显卡，本软件也能快速锁定软件使用的显卡，或者在多个显卡之间做负载均衡。

**内存。** 同时，智能调度会对内存进行持续的智能优化。

**CPU。** 还能智能分配核心：重要的软件将会优先分配到富余 / 性能强大的核心，并且可以触发**核心独占**和**核心锁定**，以保证稳定的高帧率。

> 💡 值得注意的是，本软件虽然使用了极其高性能的算法，但调度还是有性能损耗。CPU 多核性能过差的机器可能并没有明显的 CPU 效益提升（例如过早期的 i3、R5）。

> 🧪 本软件使用 **GPU shim** 技术进行显卡调度，这是一种较为稳定、兼容性较强的基于虚拟化的换卡技术，但不保证一定能够工作：
> - 默认对游戏和专业软件不启用该功能；
> - 如果其余软件出现兼容性问题，请自行关闭对该软件的调度；
> - 小部分主板 / 笔记本在独显直连的时候可能会关闭核显，如果此时你没有其他可用显卡，GPU 调度功能将不可用。

### 📑 优化报告

通过监控记录来识别异常软件，或者偷走你电脑性能的软件 🕵️：

- 💽 异常写盘
- 🌐 异常频次的网络通信
- 📡 异常的网络流量
- 🧠 过高的内存占用
- 🔥 过高的 CPU 占用
- ⚡ 频繁造成 / 造成长系统中断
- …以及其他异常资源行为

它可以帮你抓出**内存泄漏**、**流氓软件**、**磁盘杀手**、**问题驱动**，以及持续在后台通信的可疑软件。

> 📌 异常的网络行为可以帮你找出值得进一步调查的软件，但资源管理器不会自动判定这些通信就是遥测，也不会推断传输内容的用途。

## 🔬 详细信息

CPU 和 GPU 的详细监控信息，而不是只能看到一个简单的占用率数字，却没法找到真正的瓶颈。

**CPU 拓扑**：按 CCD、缓存层级和物理核心展示分核负载，以及每个逻辑处理器上占用最多的进程。

![CPU 拓扑](docs/screenshots/zh/06-cpu-topology.png)

**GPU 调度**：每张显卡的性能分、占用、显存、频率，以及光栅之外的专用单元占用（NVIDIA 的 RT / CUDA / Tensor，AMD 的 GCN / RDNA / CDNA，取决于显卡与驱动是否提供该计数器）。

![GPU 调度](docs/screenshots/zh/07-gpu-scheduling.png)

## 📦 安装

1. 下载最新的 Windows x64 发布包。
2. 将**整个文件夹**解压到一个固定位置。
3. 运行 `Install.cmd` 注册该目录。
4. 运行 `Start.cmd` 启动服务与桌面界面。
5. 需要时运行 `Restart.cmd` 重启服务。

服务管理会请求管理员权限，界面本身以普通用户身份运行。

更新时请保留以下目录：

```text
Config/
UserData/
```
